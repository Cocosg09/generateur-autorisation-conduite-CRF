        Dépôt sur le Google Drive

        Chaque autorisation signée (et chaque nouvelle version), avec l'autorisation préfectorale jointe pour le VPSP, est déposée dans un dossier du Google Drive de la Croix-Rouge, rangée dans un sous-dossier par bénévole (« NOM Prénom »), par un petit script installé une fois avec votre compte Google Croix-Rouge. Aucun mot de passe Google n'est confié à ce site ; les documents appartiennent à votre compte.

        Ouvrez le dossier dans Google Drive et copiez l'adresse de la page. Les documents déjà déposés restent où ils sont si vous changez de dossier. Ouvrir le dossier actuel

        1. Ouvrez script.google.com avec votre compte Google Croix-Rouge et cliquez sur « Nouveau projet ».
        2. Remplacez tout le code par celui ci-dessous, puis enregistrez.
        3. Dans la barre du haut, choisissez la fonction installer, cliquez sur « Exécuter » et acceptez les autorisations demandées.

        Ce code contient une clé personnelle, affichée une seule fois : ne le partagez pas. Pour en changer, générez un nouveau script ; l'ancien cesse aussitôt de fonctionner.

        Croix-Rouge française – Délégation territoriale de l'Ariège.
